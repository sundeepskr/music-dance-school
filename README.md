# Aarohi Sangeetalaya - Music, Dance & Fine Arts Institute

A modern, responsive, and SEO-optimized website for **Aarohi Sangeetalaya**, affiliated with **Prayag Sangeet Samiti, Allahabad**.

---

## 🌟 Key Features

* **Regal Indian Classical Aesthetic**: Styled with Deep Maroon (`#6B1426`), Warm Gold (`#DDA83B`), and Soft Cream (`#FAF7F2`) with Cinzel and Playfair Display typography.
* **100% Mobile Responsive**: Seamless mobile navigation drawer, fluid touch interactions, sticky header with mobile optimizations, and zero layout shift.
* **SEO & Social Optimization**: Full meta tags, OpenGraph / Twitter Cards, structured JSON-LD schemas (`MusicSchool`), canonical URLs, `robots.txt`, and `sitemap.xml`.
* **Interactive YouTube Showcase**: Curated Indian classical performances (Kathak, Tabla, Classical Vocal, Harmonium) with instant embedded video switcher.
* **Auto-Fit Masonry Gallery**: Multi-column masonry layout where dancers' heads and feet are never cropped, regardless of photo aspect ratio.
* **Instant Inquiries & Booking**: One-click WhatsApp chat integration and modal for Free Trial Class bookings.
* **Owner Photo Management**: Secure client-side event photo uploader with local storage persistence and auto-compression.

## 🚀 Getting Started

### Local Development
Open any `.html` file directly in a modern web browser, or run a local web server:
```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```
Visit `http://localhost:8080` in your browser.

### Deployment
This static site can be hosted instantly on:
* **Netlify**: Drag and drop the `music-dance-school` folder into [Netlify Drop](https://app.netlify.com/drop).
* **GitHub Pages**: Enable Pages in Repository Settings -> Pages -> Deploy from branch (`main`).
* **Vercel / Cloudflare Pages**: Connect the GitHub repository directly for automatic continuous deployment.
